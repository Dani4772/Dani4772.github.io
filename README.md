# Muhammad Adnan Ameen — Portfolio

## Free hosting + free domain
Recommended: GitHub Pages.

1. Create/sign in to GitHub.
2. Create a public repository named `Dani4772.github.io` (or use your own GitHub username).
3. Upload `index.html`.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/root`, then save.
6. Your free site will be available at `https://YOUR_GITHUB_USERNAME.github.io/`.

The included portfolio uses only HTML/CSS/JavaScript, so no paid server or database is required.
